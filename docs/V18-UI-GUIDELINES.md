# V18 UI readability guidelines

- Korean mode: general UI, dialogue and buttons in Korean; bilingual names, offices, parties and institutions when reliable Korean labels exist. English mode remains English. Do not invent names.
- Prioritize the next action. Gold for recommended work, blue for optional work, green for rest. Distinct disabled states. Color is never the sole cue.
- Display readable metrics and signed changes. Use portraits beside identities and preserve anonymity in name quizzes.
- Separate questions, answers and evidence; preserve full historical article content and concise disclaimers.
- News priority: red for breaking, gold for major, neutral for daily. Explicit unread labels.
- Responsive layout with wrapping and adequate touch targets.
- Do not change saved-career schema, rewards or historical data in presentation work. Bump service-worker shell and verify cache retirement after UI changes.
