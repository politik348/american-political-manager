# P1 R2 — Wikimedia pilot

Existing P1 receipt and assets are preserved. Run `python -m pip install requests Pillow` and `python scripts/p1-auto-portraits.py --limit 20` from a clone. The GitHub Actions pilot targets only the P1 branch; it cannot merge main. `--expand --limit 100` is available after pilot review. Output candidates are quarantined in assets/p1-portraits, with provenance in data/p1-portraits.json. These are metadata matches, not visually approved photos and are not yet wired into the game. A temporary error is never evidence of missing photos. No manual requests are generated. Commons search hits, uncertain rights, ambiguous people, and missing P18 require additional review. Official-government fallback, dynamic governors, full cross-source identity resolution, visual review, game integration/credits and browser tests remain pending. See https://www.mediawiki.org/wiki/API:Etiquette and https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia.
