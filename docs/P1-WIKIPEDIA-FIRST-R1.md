# P1 3.0 Wikipedia-first hybrid collector

Preserves all 56 existing assets, campaign history (59 attempted, 37 new), approval gate and persisted server backoff. Wikipedia PageImages is preferred when the stored article maps to the validated QID. Wikipedia title lookup up to 50 per call, Wikidata entity lookup up to 50 per call, Commons image metadata up to 10 per call. The existing conservative identity/rights validation and local WebP pipeline remain. Wikidata P18 and known official Commons files are fallback; further Commons leads are recorded, not automatically approved. Independent US government provider ingestion remains future work. No parallel requests; 12-second interval remains. API errors do not reset campaign; server pause during prefetch checkpoints without counting unattempted IDs. Offline mock tests cover title redirects, batching/cache and backoff propagation. Sources: https://www.mediawiki.org/wiki/API:Pageimages ; https://www.mediawiki.org/wiki/API:Imageinfo ; https://www.mediawiki.org/wiki/API:Query .
