# P1 3.1 Wikipedia ONLY

User requested removal of separate Wikidata and Commons API calls. The sole API endpoint is en.wikipedia.org/w/api.php, batching representative image and file metadata queries. Existing stored article titles and optional stored QIDs are used for candidate association; no name-only automatic association without a stored QID. Wikipedia can return metadata of shared Commons files (including missing local page flag). Downloads still originate from upload.wikimedia.org for Commons-hosted images; a Wikipedia article does not host image bytes itself. No license gate removed. Missing license or insufficient association is held, not bypassed. Existing request spacing and saved backoff preserved; supersede the older workflow with cancellation to prevent parallel collection, so any uncommitted progress may be lost. Existing committed assets and campaign history preserved. Source: https://www.mediawiki.org/wiki/API:Imageinfo ; https://commons.wikimedia.org/wiki/Commons:Machine-readable_data ; https://www.mediawiki.org/wiki/Wikimedia_APIs/Rate_limits. Offline tests cover exact redirects, shared-file metadata, single API host and backoff. Live compatibility is unverified until workflow executes.
