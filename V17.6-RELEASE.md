# V17.6 — guided player experience
- Four entry modes: tutorial, career, historical challenges, collection. Separate browser save slots. Existing apm-save-v1 career data is retained and offered as Continue.
- Guided 1960 tutorial uses actual eight-week fictional campaign rules, with inline inbox, activity, debate and returns. Objectives derive from completed actions, and next-week is disabled until requirements are met.
- Career overview shows quarterly tasks, next target office and a contemporary historical profile. Congress/party access is introduced after elected office (legacy party progress preserved). Historical library remains available.
- Six grouped navigation sections, mobile responsive layouts and mode-specific menus. No removal of existing modules.
- Easy/normal/hard changes fictional starting scores and AI pressure; independent challenges also use different starting budgets. Career funds are not minted by repeatedly starting and abandoning a race.
- Browser local autosave per mode, language switch, save import/export and PWA shell updates.
- No new presidential cabinet simulation or Unity build. These changes are web-first.
- Direct checks cover syntax, objective state, 60 scenario/difficulty paths, mode saves, UI generation and progression. Automated browser tests are included; deployed browser/device execution still requires confirmation.
