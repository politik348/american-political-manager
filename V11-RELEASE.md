# American Political Manager V11.0
Integrated web development build covering V8–V11. V12 specialized political-science course is deliberately excluded.
- V8: 136 curated cross-office people, including 22 unique presidents serving after 1900, 26 vice presidents, Supreme Court members, selected presidential candidates and activists. Terms are year-level approximations, not exact dates. Existing congressional/governor imports continue separately. Some people may occur in more than one dataset. Source-linked record summaries, not comprehensive bilingual biographies. Some names remain English; historical portraits depend on upstream availability and license. Existing local portraits are reused by ID/name.
- V9: eight fictional career skills, XP/levels, quarterly training, seven campaign actions, optional fictional nomination contest, staff hiring/dismissal and upkeep, reputation, retirement and successor legacy. These are game abstractions, not forecasts or a full FM simulation.
- V10: 19 sourced historical event scenarios, related people, and one fictional career response per event. Choices do not rewrite actual history; the existing alternate-history legislature is separate.
- V11: 29 associated person cards; five starter cards, unlocks through events or knowledge points, five-card deck, three distinct-card rounds, score, win/loss and save. Single-player historical matching strategy, not competitive online TCG.
- Language: Korean with English terminology, English-only toggle, incomplete transliteration for the full directory.
- PWA cache includes new JSON and JS. Prior saves migrated for old exec IDs. Real Pages browser, complete portrait coverage and Unity build not confirmed. V11 JSON data are copied to unity/Assets/APM/Data; new V9–11 JavaScript rules/UI are not yet ported to C# (V13 is deferred).
Sources: https://www.whitehouse.gov/walk-of-fame/ ; https://www.senate.gov/about/officers-staff/vice-presidents.htm ; https://www.supremecourt.gov/about/members_text.aspx ; https://www.archives.gov/electoral-college/results ; https://www.archives.gov/milestone-documents/list ; https://www.loc.gov/classroom-materials/womens-suffrage/ ; https://kinginstitute.stanford.edu/ . Individual scenario sources stored in JSON. Test with npm test.
