# APM V17 — integrated game loop
V12–V17 are implemented in the web development build. V18 card strategy expansion and V19+ are excluded.
- War room: eight fictional campaign weeks; contemporaries from the records can appear as simulated rivals. No assertion of actual candidacy for the selected seat. Campaign scores are invented game values, not polls, probabilities, forecasts or politician ratings.
- Weekly inbox with six dilemma templates; quarterly decisions outside campaigns; source-linked historical news. Each week requires one move and one response.
- Two three-question debates, six weekly moves, rival AI actions and score history; five-step election-night reveal. Career races start in eligible election-year Q4. Presidential challenges are simplified two-candidate score games, not an Electoral College simulation.
- Relationships: fictional contact/ally/rival classification, quarterly actions. Party: three fictional factions, treasury, unity, influence, six-person scouting roster, training and leadership contest. Not historical faction membership or national seat control.
- 20 presidential-election challenges (1900–2016) from existing National Archives election records. Actual historical winner and source link shown separately; game settings are fictional. Independent of main career resources; achievement history persists.
- Existing cards, career, atlas and Congress modules retained. New menus share local autosave; PWA cache includes new modules/data. Korean/English UI. Pictures still depend on local assets/upstream availability.
- Verification: JS syntax, engine flow, 20 scenario completions, action locks and generated UI checked. npm test includes automated regressions. Actual Pages browser/mobile install and Unity port/build not verified. New JS code is modular but has not been ported to C#.
Source: https://www.archives.gov/electoral-college/results
